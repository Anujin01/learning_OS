## 🛠️ Windows Command Prompt (CMD) Basics
Before diving into Linux, I practiced some essential networking and system discovery commands on the Windows Command Prompt:

| Command | Description | What It Does |
| :--- | :--- | :--- |
| `hostname` | **Computer Name** | Outputs the unique network name of the machine. |
| `whoami` | **Current User** | Displays the username of the account currently logged in. |
| `ipconfig` | **IP Configuration** | Shows network address settings, including IP and gateway details. |
| `netstat` | **Network Statistics**| Displays active TCP/IP connections and protocol statistics. |
